# My Winkel block packages

The public [block author guide](https://mywinkel.github.io/blocks/) documents the
released package contract for external authors. The internal [storefront contract]
(../devdocs/src/content/docs/systems/storefronts.md) records CMS integration and
ecosystem behavior. Keep packages independent of the private CMS and preserve
block identities. Keep hand-maintained files below 1,000 lines. Run package
checks and tests, plus CMS consumers and demo validation for releases.
