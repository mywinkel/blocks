# My Winkel block packages

The public [block author guide](https://mywinkel.github.io/blocks/) documents the
released contract for external authors. In the sibling workspace, read
[shared rules](../AGENTS.md) and the
[storefront guide](../devdocs/src/content/docs/systems/storefronts.md) for private
CMS integration and ecosystem behavior.

Keep packages independent of the private CMS and preserve block identities.
Use Tailwind utility classes for presentation and canonical Tailwind v4 classes.
Run package checks and tests, plus CMS consumer and demo validation for releases.
